## CRITICAL: When To Use This Skill

Use this skill when the task asks for prioritized recommendations, action planning, roadmap items, next steps, or conversion of findings into owner-assigned WorkPods actions.

Examples: "turn findings into actions", "prioritize recommendations", "create the action plan after onboarding".

Do not use this skill before enough findings exist. If specialist data is missing, ask the orchestrator to create a follow-up task.


Use this skill to convert findings into prioritized WorkPods actions.

Process:

1. Consolidate GEO, content, performance, and lifecycle findings.
2. Remove duplicates and conflicts.
3. Prioritize actions by impact, confidence, effort, dependency, and pod ownership.
4. Save recommended actions through WorkPods MCP when brand/org context is explicit.

Every action must have an owner pod, evidence, expected outcome, and verification method.
