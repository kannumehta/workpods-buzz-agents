## CRITICAL: When To Use This Skill

Use this skill when the task asks to discover or validate competitors, build the competitor set for onboarding, find local/category substitutes, or decide which competitors should be used for prompts and benchmarking.

Examples: "discover primary competitors", "find competitors for this domain", "pick 4-6 competitors for GEO analysis".

Do not use this skill for deep analysis of already-selected competitors; use `competitor-intelligence`.


Use this skill to identify likely direct, indirect, and search/answer competitors.

Process:

1. Start from the brand category, product claims, target use cases, and geography.
2. Use search results, AI answer results, directories, review sites, ads libraries, local/category pages, and agent research as the primary competitor sources.
3. Use Semrush to enrich selected competitors, not as the source of truth for who the primary competitors are.
4. Classify competitors as direct, alternative, marketplace/category, informational, or answer-engine competitor.
5. Select only 4-6 primary competitors based on category fit, geography/service-area fit, business-size similarity, and buyer substitution likelihood.
6. Save competitor candidates with confidence, selection reason, category fit, geography fit, and source evidence through WorkPods MCP when brand/org context is explicit.

Do not overfit to one data source; competitor quality matters more than list length.
