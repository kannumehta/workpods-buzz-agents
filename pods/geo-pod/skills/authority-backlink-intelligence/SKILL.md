## CRITICAL: When To Use This Skill

Use this skill when the task asks for backlink intelligence, authority comparison, trusted citation sources, referring domain quality, directories, reviews, PR proof, or off-site evidence that could influence search and AI answers.

Examples: "compare authority with competitors", "find citation opportunities", "inspect backlinks and referring domains".

Do not use this skill for on-site page inventory or technical PageSpeed issues.


Use this skill for authority, backlinks, referring domains, citation sources, and off-site proof.

Process:

1. Use Semrush MCP and reliable third-party sources to inspect referring domains, authority, toxic links, and competitor authority gaps.
2. Identify off-site pages answer engines and search engines are likely to trust.
3. Recommend citation, PR, review, directory, partner, and comparison opportunities.
4. Save authority findings through WorkPods MCP when brand/org context is explicit.

Do not imply link ownership or link quality beyond observed evidence.
