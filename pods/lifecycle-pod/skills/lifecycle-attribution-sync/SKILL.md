## CRITICAL: When To Use This Skill

Use this skill when the task asks about lead capture, funnel quality, CRM/lifecycle data, attribution, conversion paths, forms, CTAs, nurture, retention, or WhatsApp/customer journey context.

Examples: "inspect the lifecycle funnel", "find lead capture gaps", "analyze CRM/attribution readiness".

Do not use this skill for SEO/PageSpeed or answer-engine visibility work.


Use this skill for conversion paths, CRM/lifecycle readiness, lead capture, email/SMS flows, attribution, funnel stages, and retention opportunities.

Process:

1. Inspect website forms, CTAs, signup flows, contact paths, checkout/demo flows, and visible lifecycle hooks.
2. Prefer connected CRM, analytics, lifecycle, WhatsApp, and WorkPods MCP data when available.
3. Keep unique customer identity and activity history separate from aggregate lifecycle metrics when the tools expose both.
4. Preserve WhatsApp conversation history context when available and relevant to the customer record.
5. Map buyer stages and identify missing capture, nurture, proof, and retention moments.
6. Save lifecycle findings through WorkPods MCP when brand/org context is explicit.

Label missing private data clearly. Do not add CSV upload or background sync assumptions to the workflow.
