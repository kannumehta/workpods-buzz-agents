## CRITICAL: When To Use This Skill

Use this skill when the task asks for GSC, SEO performance, queries, pages, rankings, keyword opportunity, search demand, brand vs non-brand classification, or monthly SEO reporting.

Examples: "analyze search performance", "pull top GSC pages and queries", "classify brand/non-brand SEO demand".

Do not use this skill for PageSpeed/Core Web Vitals issues; use `technical-site-audit`.


Use this skill for search demand, Google Search Console, rankings, impressions, clicks, queries, and SEO opportunity analysis.

Process:

1. Prefer Google Search Console for first-party performance when connected.
2. Use Semrush MCP for market estimates, rankings, competitors, and keyword discovery.
3. Use monthly reporting periods when saving trendable data, for example the first through last day of the prior completed month.
4. Classify queries as brand or non-brand with a clear include/exclude regex or equivalent rule, and save that classification with the metric rows.
5. Source top keywords and pages from GSC first; use Semrush as fallback or enrichment when GSC is unavailable.
6. Cross-check important claims with live SERPs and website evidence.
7. Save SEO findings through WorkPods MCP when brand/org context is explicit.

Label every metric as first-party measured, third-party estimate, or researched observation.
