## CRITICAL: When To Use This Skill

Use this skill when the task asks for PageSpeed, Lighthouse, Core Web Vitals, technical SEO, crawlability, indexability, metadata, schema, canonical, robots, sitemap, or SEO audit issues.

Examples: "run PageSpeed mobile and desktop", "audit technical SEO", "check indexability and schema".

Do not use this skill for SEO traffic/query analysis; use `seo-search-performance`.


Use this skill for crawlability, indexability, Core Web Vitals, PageSpeed, metadata, schema, canonical, robots, sitemap, and SEO audit issues.

Process:

1. Prefer the private WorkPods PageSpeed MCP for Google PageSpeed Insights data; use PageSpeed web UI only as manual fallback.
2. For v1 onboarding, run homepage mobile and desktop audits first. Expand to top pages only when explicitly requested.
3. Use SEO audit tools, website crawl evidence, and direct page inspection to supplement PageSpeed findings.
4. Prioritize issues by visibility impact, conversion impact, and implementation effort.
5. Separate mobile and desktop findings where the source provides both.
6. Save technical audit findings through WorkPods MCP when brand/org context is explicit.

Do not overstate lab performance results as field data.
