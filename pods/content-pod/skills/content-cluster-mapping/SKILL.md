## CRITICAL: When To Use This Skill

Use this skill when the task asks for topical coverage, content clusters, content gaps, page-to-keyword/prompt mapping, buyer journey content, or content briefs.

Examples: "map content clusters", "find topical gaps", "connect pages to prompts and keywords".

Do not use this skill before basic website inventory and product/service understanding exist.


Use this skill to map topical coverage and content gaps.

Process:

1. Combine website inventory, product/service catalog, competitor content, Semrush keyword/topic data, and answer-engine prompt gaps.
2. Build clusters by buyer problem, use case, product category, comparison, FAQ, proof, and implementation.
3. Map each cluster to related prompts, keywords, owned pages, target pages, and competitor pages where evidence exists.
4. Keep prompt, keyword, and page mappings explicit enough to support month-over-month and competitor comparisons later.
5. Score clusters by business relevance, current coverage, visibility gap, and likely execution value.
6. Save cluster maps and recommended briefs through WorkPods MCP when brand/org context is explicit.

Prefer fewer high-quality clusters over exhaustive keyword dumping.
